# Mini Games — сайт мини-игр

## Описание

Веб-приложение с коллекцией интерактивных мини-игр в браузере. На главной странице можно познакомиться с играми и запустить любую из них одной кнопкой.

**Доступные игры:**

1. **Угадай число** — угадайте случайное число от 1 до 100.
2. **Простая арифметика** — решайте примеры на сложение, вычитание, умножение и деление.
3. **Переверни текст** — введите строку и получите её в обратном порядке.
4. **Камень, ножницы, бумага** — игра против компьютера.
5. **Простая викторина** — вопросы с вариантами ответов.
6. **Генератор случайных цветов** — меняет фон страницы на случайный цвет.

В репозитории также хранятся учебные задания по JavaScript (`hw2.js` — `hw9.html`) для курса веб-разработки.

## Запуск проекта

Проект не требует установки зависимостей — это статический сайт на HTML, CSS и JavaScript.

### Локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/highscroller/2nd_course_hw.git
   cd 2nd_course_hw
   ```
2. Откройте файл `index.html` в браузере (двойной клик или через расширение **Live Server** в VS Code / Cursor).

Для корректной работы некоторых функций браузера удобнее запустить локальный сервер:

```bash
npx serve .
```

или

```bash
python -m http.server 8000
```

После этого откройте в браузере адрес, который выведет команда (обычно `http://localhost:3000` или `http://localhost:8000`).

### Стили (SCSS)

Стили написаны на SCSS (`style.scss`, `_vars.scss`, медиа-миксины). В репозитории уже есть скомпилированный `style.css`. Если вы меняете SCSS, пересоберите CSS:

```bash
sass style.scss style.css
```

(нужен установленный [Dart Sass](https://sass-lang.com/install/)).

## Технологии

- **HTML5** — разметка страниц
- **CSS3 / SCSS** — стили, адаптивная вёрстка (desktop / tablet / mobile)
- **JavaScript (ES6+)** — логика игр и домашние задания
- **Google Fonts** — шрифт Montserrat

Сборщики и фреймворки (React, Vue и т.д.) не используются.
